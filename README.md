# Sierpinski Carpet WebGL 구현

## 실행

이 폴더에서 `python3 -m http.server 8765`를 실행하고 Chrome에서 `http://localhost:8765/`를 연다. 외부 라이브러리와 빌드 과정은 없다. `index.html`을 직접 열어도 동작하도록 작성했지만, 검증은 로컬 HTTP 서버에서 했다.

## 조작

- 분할 횟수: 0~5회. 0회는 꽉 찬 정사각형이다.
- 도형 색상: 남은 정사각형의 색을 바꾼다.
- 빈 공간 색상: 가운데 구멍과 캔버스 배경색을 바꾼다.

`app.js`가 CPU에서 재귀 분할 후 정점 배열을 만들고, WebGL이 이를 삼각형으로 그린다. 깊이 5에서는 작은 정사각형 32,768개, 삼각형 65,536개, 정점 196,608개를 생성한다.

## 작성 및 검증

2026-09-25 OpenAI Codex가 초기 코드와 설명을 작성했다. 과제 원문과 관련 강의자료를 확인한 뒤 Chrome에서 분할 0·3·5회 및 색상 변경을 실행해 검증했다. 사용 이유와 과정은 제출 보고서에 상세히 기록한다.
